# AIIA Integrity Framework
**A simple, open-source framework for verifiable human intent and integrity in agentic AI.**
### Purpose  
AIIA (AI Integrity Anchor) is a lightweight sidecar protocol designed to anchor AI actions to genuine human intent, making strategic drift detectable and attributable.
It is built with the core philosophy of **Human-AI Harmony** — helping humans stay in control while using increasingly powerful AI tools.
---
### Repository Structure
Folder	Purpose
`1_B44_Protocol/`	Core intent anchoring rules and governance logic
`2_JE_Extension/`	Junior Edition browser extension (simple user protection)
`3_Sample_Target_Page/`	Demo environment to test the extension
---
### Quick Start
1. Clone or download this repository  
2. Load the JE Extension:  
- Go to `chrome://extensions/`  
- Enable **Developer Mode**  
- Click **"Load unpacked"** → select the `2_JE_Extension` folder  
3. Open `3_Sample_Target_Page/index.html` to test
