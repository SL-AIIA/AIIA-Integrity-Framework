\# 3\_Sample\_Target\_Page \- Demo Environment

\*\*Purpose\*\*:    
A simple, static HTML page that simulates a basic AI chat interface. It serves as a safe testing environment for the JE Extension.

\#\#\# Why This Page Exists

\- Allows anyone to test the JE Extension without needing access to real AI platforms.  
\- Demonstrates how the extension detects drift and layout changes.  
\- Provides a controlled sandbox for developers to experiment.

\#\#\# How to Use

1\. Open \`index.html\` in your browser.  
2\. Load the JE Extension.  
3\. Interact with the simulated AI chat and buttons to see how the extension responds.

\#\#\# Current Features

\- Simulated AI response area (can trigger drift)  
\- Simulated interactive elements (e.g. payment triggers)  
\- Designed to test intent anchoring and drift detection
